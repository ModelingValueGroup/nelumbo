# sudoku2.nl MRV Solver Implementation Plan

> **Completed 2026-09-10 with major deviations.** Tasks 1-3 ran as planned;
> Tasks 4-6 (elim/init/best) were abandoned when probes showed the engine
> cannot run the candidate-grid design (see the spec's Outcome section).
> The shipped solver is singles-first guard-pruned recursion
> (scanF/scanB/solveBX); all four puzzles green in one ~45s CLI run.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** New example `src/main/resources/org/modelingvalue/nelumbo/examples/sudoku2.nl`: a candidate-grid sudoku solver with fewest-candidates-first search that solves hard puzzles in reasonable time.

**Architecture:** Digit grid `g` + parallel candidate grid `cg` threaded through the recursion. One `map` pass per grid per placement (no `ok()`, no `rowsBefore`/`rowsFrom`). Cell selection by a single min-scan (`best`) whose result `[size,r,c]` drives: size 10 = solved, 0 = dead branch (instant fail), 1 = forced move, else minimal branching. Spec: `docs/superpowers/specs/2026-09-10-sudoku2-mrv-design.md`.

**Tech Stack:** Nelumbo `.nl` (nelumbo.collections stdlib), CLI jar for verification, one throwaway Java single-file tool for puzzle verification.

**Verification loop (every task):**
```sh
java -DPARALLEL_COLLECTIONS=false -jar cli/build/libs/nelumbo-cli-dev.jar src/main/resources/org/modelingvalue/nelumbo/examples/sudoku2.nl
```
Expectations are in the queries themselves (`? [(...)][..]`); a mismatch prints in the output. Time the runs (`time`). The `.nl` query expectations ARE the tests (TDD: each task writes queries + minimal predicates to satisfy them).

**Known engine facts:** run CLI with `-DPARALLEL_COLLECTIONS=false` (interning bug). `/` is exact division (no div/mod). No tuples. Syntax shapes proven in `sudoku.nl`/`collectionsTest.nl`: guarded comma-alternatives with `&`-only guards, `!E[...]`, `E[a,b](...)` conjunction bodies, `map`/`where` with closures, `d in <set>` enumeration, nested functor args.

```
// digit grid g: List<List<Integer>>, 0 = blank
// candidate grid cg: List<List<Set<Integer>>>, {} = placed, else candidates

Integer                  ::= at(<List<Integer>>,<Integer>),

                             colSet(<List<List<Integer>>>,<Integer>),
                             boxSet(<List<List<Integer>>>,<Integer>,<Integer>),
                             cands(<List<List<Integer>>>,<Integer>,<Integer>),
                             elimCell(<Set<Integer>>,<Integer>,<Integer>,<Integer>,<Integer>,<Integer>),
                             initCell(<List<List<Integer>>>,<Integer>,<Integer>)
List<Integer>            ::= row(<List<List<Integer>>>,<Integer>),
                             putRow(<List<Integer>>,<Integer>,<Integer>),
                             putIf(<List<List<Integer>>>,<Integer>,<Integer>,<Integer>,<Integer>),
                             best(<List<List<Integer>>>,<List<List<Set<Integer>>>>,<Integer>,<Integer>,<List<Integer>>),
                             best2(<List<List<Integer>>>,<List<List<Set<Integer>>>>,<Integer>,<Integer>,<List<Integer>>)
List<Set<Integer>>       ::= crow(<List<List<Set<Integer>>>>,<Integer>),
                             elimRow(<List<Set<Integer>>>,<Integer>,<Integer>,<Integer>,<Integer>),
                             initRow(<List<List<Integer>>>,<Integer>)
List<List<Integer>>      ::= put(<List<List<Integer>>>,<Integer>,<Integer>,<Integer>),
                             solve(<List<List<Integer>>>,<List<List<Set<Integer>>>>),
                             step(<List<List<Integer>>>,<List<List<Set<Integer>>>>,<List<Integer>>),
                             sudoku2(<List<List<Integer>>>)
List<List<Set<Integer>>> ::= elim(<List<List<Set<Integer>>>>,<Integer>,<Integer>,<Integer>),
                             init(<List<List<Integer>>>)

List<List<Integer>>      g, g2, s
List<Integer>            l, rw, rw2, b
List<List<Set<Integer>>> cg, cg2
List<Set<Integer>>       crw, crw2
Set<Integer>             bs, bc, cs, ds
Integer                  r, c, d, x, y, i, j, n

// ---- access ---------------------------------------------------------
at(l,i)=x        <=>  x pos l = i
row(g,r)=rw      <=>  rw pos g = r
cell(g,r,c)=x    <=>  x = at(row(g,r),c)
crow(cg,r)=crw   <=>  crw pos cg = r
sat(crw,c)=cs    <=>  cs pos crw = c
cval(cg,r,c)=cs  <=>  cs = sat(crow(cg,r),c)

// ---- update (functional) -------------------------------------------
sel(j,i,d,x)=y      <=>  y=d if j=i,  y=x if j!=i
putRow(l,i,d)=rw    <=>  rw = [0,1,2,3,4,5,6,7,8] map [j](sel(j,i,d,at(l,j)))
putIf(g,i,r,c,d)=rw <=>  rw=putRow(row(g,i),c,d) if i=r,  rw=row(g,i) if i!=r
put(g,r,c,d)=g2     <=>  g2 = [0,1,2,3,4,5,6,7,8] map [i](putIf(g,i,r,c,d))

// ---- 9x9 boxes are 3 rows x 3 cols ---------------------------------
boxRows(r)=bs    <=>  bs={0,1,2} if r<3,  bs={3,4,5} if r>=3 & r<6,  bs={6,7,8} if r>=6
boxCols(c)=bs    <=>  bs={0,1,2} if c<3,  bs={3,4,5} if c>=3 & c<6,  bs={6,7,8} if c>=6

// ---- tests ----------------------------------------------------------
at([4,5,6],1)=x                       ? [(x=5)][..]
sat([{1},{2,3}],1)=cs                 ? [(cs={2,3})][..]
putRow([1,0,3,0,5,6,7,0,9],1,8)=l     ? [(l=[1,8,3,0,5,6,7,0,9])][..]
boxRows(3)=bs                         ? [(bs={3,4,5})][..]
boxCols(7)=bs                         ? [(bs={6,7,8})][..]
```

```
// ---- candidate elimination: place d at (r,c) -----------------------
elimCell(cs,i,j,r,c,d)=ds <=>
    ds = {}       if i=r & j=c,
    ds = cs - {d} if i=r & j!=c,
    ds = cs - {d} if i!=r & j=c,
    ds = cs - {d} if i!=r & j!=c & E[bs,bc](boxRows(r)=bs & boxCols(c)=bc & i in bs & j in bc),
    ds = cs       if i!=r & j!=c & !E[bs,bc](boxRows(r)=bs & boxCols(c)=bc & i in bs & j in bc)
elimRow(crw,i,r,c,d)=crw2 <=>  crw2 = [0,1,2,3,4,5,6,7,8] map [j](elimCell(sat(crw,j),i,j,r,c,d))
elim(cg,r,c,d)=cg2        <=>  cg2  = [0,1,2,3,4,5,6,7,8] map [i](elimRow(crow(cg,i),i,r,c,d))
```
Queries: target cell -> `{}`; same row / same col / same box -> digit removed; non-peer -> unchanged; one full `elim` on a small uniform cg (all cells `{1,2}`), checking the four cases in the result grid.

```
// size 10 = solved; 0 = contradiction (d in {} fails); 1 = forced move
step(g,cg,l)=s <=>
    s=g   if at(l,0)=10,
```
